About Athlete Activity Recognition

This application uses advanced machine learning techniques to recognize various athletic activities in real-time using your webcam.

Supported Activities

  • Running
  • Walking
  • Squats
  • Pushups
  • Jumping Jacks
  • Stretching

Technology

Built with TensorFlow/Keras for the AI model, OpenCV for image processing, and Flask for the web framework.
